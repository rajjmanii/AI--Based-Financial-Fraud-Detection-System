# Attribution and Licensing

## Dataset
**Credit Card Fraud Detection**, Machine Learning Group, Universite Libre de Bruxelles (ULB),
published on Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

The dataset contains anonymised credit-card transactions made by European cardholders over two
days in September 2013. Please read the licence and citation request on the Kaggle page before
redistributing the data or publishing results (at the time of writing it is listed under the
Database Contents License, but check the page yourself). The dataset is **not** included in this
project; you download it separately.

Suggested citation (from the dataset page): Dal Pozzolo, A., Caelen, O., Johnson, R. A., and
Bontempi, G. "Calibrating Probability with Undersampling for Unbalanced Classification." IEEE
Symposium on Computational Intelligence and Data Mining (CIDM), 2015.

## Synthetic data
`data/sample/sample_transactions_SYNTHETIC.csv` and the `--demo` training mode use randomly
generated numbers. They are not real transactions and are for testing the file format and the
software only.
